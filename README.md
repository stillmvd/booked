# Booked

Личное хранилище закладок под Windows 11. Tauri 2 + React + TypeScript, ядро на Rust,
хранилище SQLite через `rusqlite` (bundled). Контекст проекта, требования и роадмап —
в `.planning/`.

## Установка и обновления

Установщик — `Booked_<версия>_x64-setup.exe` из [релизов](https://github.com/stillmvd/booked/releases).
Он ставит приложение в `C:\Program Files\Booked`, поэтому просит права администратора (у обычной
учётной записи Windows спросит пароль администратора), показывает только прогресс и сразу открывает
Booked. Мастера и выбора папки нет. Поверх старой версии ставится без вопросов: запущенное
приложение закрывается само. Данные остаются в `%LOCALAPPDATA%\com.stillmvd.booked`.

Обновления — по стандарту [`stillmvd/tauri-ship`](https://github.com/stillmvd/tauri-ship): приложение
проверяет новую версию через 5 секунд после запуска, раз в час и при возврате в окно, скачивает её в
фоне и показывает тост «Перезапустить / Позже»; после «Позже» в титлбаре остаётся значок с версией.
Настройки → «Обновления»: установленная версия, «Проверить», время последней проверки.

## Облако игр

Игры с F95zone связаны с расширением Sorter 95 через личное облако — воркер Cloudflare в `cloud/`
(устройство и деплой — `cloud/README.md`). Настройки → «Облако»: адрес, ключ и состояние синка
(«Подключено», «Ждут отправки: N», «Неверный ключ», «Нет связи»). Пустой ключ («Отключить») —
синк выключен, Booked работает как раньше.

- **Что уходит**: только игры со ссылкой на тред F95 — статус, звёзды, установленная версия и версия
  на сайте, название (с сайта или своё, не из имени папки), движок, есть ли папка, «убрана из списка»,
  «Убрать» и «Не нравится» у карточек «Хочу».
- **Что не уходит никогда**: закладки, папки и теги закладок, свои теги игр, обложки, пути к папкам,
  настройки, игры itch и без ссылки.
- **Как**: правки игр сразу пишутся в очередь в базе (триггеры миграции 020), фон отправляет их через
  несколько секунд и забирает чужие раз в 50 секунд. Спор решает последняя правка по каждому полю. Без
  сети очередь ждёт и уходит сама.
- **Версия из ленты**: если расширение увидело новую версию игры, метка обновления в Booked появляется
  после ближайшего синка, без суточной проверки.
- **Ключ** хранится в Диспетчере учётных данных Windows («Booked cloud»), не в базе и не в копиях; в
  настройках виден только хвост из 4 символов.

### Статусы и «Хочу»

- **Шесть статусов**: Хочу → Не начата → Прохожу → Пройдена | Жду обновлений | Не понравилась. Руками в
  панели игры выбираются пять (кроме «Хочу»), двумя группами: путь и итог. Прежние «Брошена» при
  обновлении стали «Не понравилась» (миграция 021); расширение банит такие игры на F95.
- **«Хочу»**: «Нравится» в расширении создаёт в Booked карточку без папки — название, версия на сайте,
  движок, статус разработки, вес, ссылка на тред; обложка скачивается в фоне. Такие карточки живут в
  плитке «Хочу» и не попадают во «Все», счётчики и «Без папки». Правый клик — «Убрать» (в расширении игра
  снова нерешённая) или «Не нравится» (бан на F95).
- **Склейка**: папка той же игры (имя папки совпало с названием или у новой карточки указан тот же тред)
  сливается с карточкой «Хочу» в одну «Не начата» с обложкой и ссылкой.
- **«Не понравилась»** у игры с папкой предлагает тостом удалить папку; без согласия папка остаётся.
  Разбан в расширении приходит как «Жду обновлений».
- **Теги F95** в Booked не попадают: теги назначаются только вручную.

## Релиз

```bash
pnpm release   # проверки → версия по коммитам → сборка и подпись → коммит и тег → установка себе → публикация в фоне
```

Сборка локальная, CI-релиза нет. Версия живёт в `package.json`, `src-tauri/tauri.conf.json` ссылается
на него. Шаблон установщика берётся из пакета `@stillmvd/tauri-ship`.

## Сборка и TLS

Сетевой запрос закладок идёт через `reqwest`. Фичи `reqwest` в `src-tauri/Cargo.toml`:
дефолтные (не отключены) плюс `gzip` и `brotli` для прозрачной распаковки ответов.

Дефолтный стек `reqwest` 0.13 — `rustls` поверх криптопровайдера `aws-lc-rs`, с
`rustls-platform-verifier` для системных корневых сертификатов. Проверено сборкой на
этой машине 21.08.2026: `cargo build --manifest-path src-tauri/Cargo.toml` завершается
кодом 0 при полном отсутствии `cmake` и NASM в `PATH` (`where cmake nasm` не находит
ничего). В дереве зависимостей — `aws-lc-sys 0.44.0`, `aws-lc-rs 1.18.0`,
`rustls 0.23.43`, `rustls-platform-verifier 0.7.0`; `aws-lc-sys` собрался без внешнего
тулчейна за счёт предсобранных объектов в самом крейте.

**Важно:** имя фичи `rustls-tls-webpki-roots`, которое встречается во внешних
источниках и черновике `FETCHING.md`, в `reqwest` 0.13.4 не существует — это фича из
линейки 0.12. Указание её в `Cargo.toml` уронит `cargo build` на разборе манифеста.

### Если дефолт всё-таки упадёт на другой машине

Лестница отступления, по возрастанию инвазивности:

1. Установить `cmake` и NASM в `PATH`.
2. Задать переменную окружения `AWS_LC_SYS_PREBUILT_NASM`, указывающую на уже собранные
   NASM-объекты, если сборка NASM недоступна, но объекты есть.
3. Отказаться от провайдера по умолчанию: `default-features = false` у `reqwest` плюс
   фича `rustls-no-provider`, и собрать собственный `rustls::ClientConfig` с нужным
   криптопровайдером вручную.

### Цена для Android v2

Дефолтный путь тянет `rustls-platform-verifier`, которому на Android нужна
инициализация через JNI, зависимость Gradle и правило ProGuard — без них приложение
падает в рантайме на первом же сетевом запросе. Запасной ход: собрать
`rustls::ClientConfig` на `webpki-roots` (без обращения к системному хранилищу
сертификатов) и передать его в `tls_backend_preconfigured`. Цена — теряются системные
и корпоративные корневые сертификаты; в обмен не нужна платформенная инициализация.

### Второй HTTP-стек не добавляется

`tauri-plugin-http` живёт на `reqwest ^0.12` и даёт в дереве два мажора `reqwest` и два
TLS-стека одновременно. В проекте ровно один HTTP-клиент — `reqwest::Client`, собранный
один раз в `setup()` и живущий в состоянии Tauri (`src-tauri/src/net.rs`).
